# esm_forecasting_app
Forecasting individual experience sampling (ESM) data in R. Includes a Shiny app to explore data and compare Naive, ARIMA and ARIMAX forecasts, plus a mixed-effects analysis of within-person associations between ESM variables.

*Note: we collaborated mainly in person to give feedback on each other's work, so much of the history in Github is a "recreation" of the different steps and versions we took. This is because we only set up the repo when we had the actual coding and files done and working, so we didn't use git to track our work*
